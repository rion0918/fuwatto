## 画面の根拠

- 対象ソース: `ca74a962d117d0f5e92ddaa3d64e70058da3a3ae`、versionCode 46。
- 対象AAB: `dist/pop-reminder-v46.aab`。SHA-256: `d342b12e6290692b9b643bbd98a5d72ed78dc3efeaf1c7c399d12ca248535a25`。
- このAABからbundletoolでuniversal APKを作り、撮影専用に既存のローカルdebug証明書で署名した。Google Playからインストールした端末ではなく、購入の検証にも使用していない。
- ユーザーがADB操作を明示承認した空の専用AVD `Fuwatto_Store_Capture_35`（API 35）で撮影。元のAVD・実機・既存リマインダーは操作していない。
- デモ予定は実際の追加画面から入力し、Widgetもランチャーから配置した。DBの直接書き換えやUIの作り直しは行っていない。
- 日本語入力と画面構造取得には専用AVDだけに導入したローカルinstrumentationを使用した。入力補助ファイルはリポジトリ外の一時ディレクトリに置いた。
- 音声の収録は行わず、音声入力は実際の初回案内を使用。通知は設定画面を使用し、通知受信画面の撮影とは扱わない。Widgetは次の予定と一覧の表示部分を切り出した。
- `raw/` の実画面をHTML/CSSで等比拡大縮小・切り出しし、ブランドと説明を追加した。生成AIによるUIの描き直しはしていない。
