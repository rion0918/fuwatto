# ADR 0008: 過ぎた予定を常に保存しホームの入口を1行にする

Date: 2026-11-17

## Status

Proposed

チャットで「自動整理と保存の二択をなくす」方針と、ホームの1行の入口の案1を選択した内容を記録する。ADR 0007の自動削除案からの変更。

## Context

ふわっと。は、生活の用事を数秒で預け、必要なときに思い出すことを支える。予定時刻を過ぎても用事が不要になったとは限らず、通知を見逃した場合の自動削除は、その用事を拾い直す手がかりも消してしまう。保存するかの選択を最初から求めることと、過去の大きなカードで主役の泡を狭めることも避けたい。

## Decision

予定日時を過ぎたリマインダーは、手動削除するまで保存する。終日は既存のその日の終わりの期限を使う。起動・復帰・期限到来では状態を期限済みへ更新し、削除や新たな自動削除の案内を行わない。ホームとWidgetの予定欄にはこれからの予定だけを表示し、過ぎた予定は専用一覧から見返し・日時変更・削除できる。

ホームの入口は「過ぎた予定 N件 ›」の1行にし、枠・背景・説明文を持たせない。44dp以上のタップ領域を保ち、0件では非表示にする。設定から自動消滅とその説明・「泡と音声入力」の見出しを除き、音声入力の操作と説明図は維持する。

旧 `auto_delete_enabled` の保存列・APIは互換性のため残すが、値にかかわらずアプリとWidgetは過去の予定を保持・表示する。旧検証ビルドの削除済み案内は、既存の確認経路だけを維持する。新たな案内は作らない。

見送った案:

- 今日の終わりや翌日を保存期限にする: 用事がいつまで必要かは日付だけでは判断できない。
- 自動削除と保存を同じ重さで選ばせる: 同じ人でも用事によって必要性が違い、全体設定の選択に負担がある。
- 過ぎた予定のカードやプレビューを大きく置く: これからの泡が使える面積を減らす。

## Consequences

- 利点: 通知時刻を過ぎても用事を拾い直せる。整理操作をしなくてもホームの主役はこれからの予定になる。
- 利点: 旧設定がONでも新たなデータ消失を起こさず、Widgetからも同じ一覧に到達できる。
- 受け入れる欠点: 手動削除するまで内容が端末内に蓄積する。削除方法と保持方針の説明も更新する。
- 受け入れる欠点: 1行の入口では予定名をプレビューしない。内容の確認には1回タップが必要になる。

確認方法: 旧設定の両値で保存・一覧・Widget件数を検証する。Android Development Buildで1行の入口、0件、過去だけの状態、日時変更による泡への復帰、音声入力の従来表示を確認する。
