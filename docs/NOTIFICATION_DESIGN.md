# 通知文言・情報設計メモ（前日・当日通知）

## 目的

前日通知と当日通知の役割を明確に分け、通知を開かなくても「何の予定が・いつあるか・今なにをする知らせか」を一目で理解できる体験にする。

## 設計方針と調査根拠

1. **タイトルに具体情報、本文に役割を置く**
   - Apple Human Interface Guidelines（Notifications）は、タイトルに予定名などの具体的な情報を置き、本文を簡潔にすることを推奨している。
   - 従来の当日通知タイトル「ふわっと。」と前日通知タイトル「前日のお知らせ」を廃止し、日時と予定名をタイトルへ移動した。
2. **「前日は準備、当日は実行」の設計仮説**
   - 事前に計画を思い出させる通知が、計画の想起や実行を助けた研究報告を踏まえ、前日を「準備のきっかけ」、当日を「行動の合図」と位置づけた。
   - ただし、本アプリ特有の日本語文言や二回通知の優位性自体が証明されたわけではないため、設計仮説として実機評価で確認する。
3. **アイコンはアプリ識別、文字で種別区別**
   - Android の通知小アイコンは単色シルエット（白い泡アイコン）として扱われるため、アイコンの出し分けではなくテキストの冒頭（`明日` / `今日` と時刻）で前日・当日を確実に区別する。

## 採用文言（4パターン）

| 種類           | タイトルの例                   | 本文                           |
| -------------- | ------------------------------ | ------------------------------ |
| 前日・時刻あり | `明日 10:00｜歯医者`           | `明日の準備を、今のうちに。`   |
| 前日・終日     | `明日｜クリーニングを受け取る` | `明日の準備を、今のうちに。`   |
| 当日・時刻あり | `今日 10:00｜歯医者`           | `予定の時間になりました。`     |
| 当日・終日     | `今日｜クリーニングを受け取る` | `今日の予定をお知らせします。` |

### フォーマット規約

- 時刻は端末のローカル時刻で 24 時間表記（`HH:mm`）を使う。前日通知にも翌日の予定時刻を表示する。
- 終日リマインダー（`allDay === true`）は通知が鳴る共通時刻を予定の開始時刻として表示しない。
- 予定名（`title`）は入力値のまま使い、内容から準備物や行動を推測して追記しない。
- 装飾用の絵文字は追加せず、長いタイトルの省略は OS に委ねる。
- `src/lib/notifications/reminderNotificationContent.ts` を唯一の生成元とし、一括予約・個別再予約・開発用テスト通知で共通利用する。

## チャンネル・表示優先度と適用条件

- 通知時刻・通知回数・泡アイコン・通知色・音・バイブレーション設定は OS の通知設定を尊重して維持する。
- Android の通知チャンネルは単一チャンネル（`reminder-alerts-high`）とし、重要度 `AndroidImportance.HIGH` と通知優先度 `AndroidNotificationPriority.HIGH` を使って、前日通知・当日通知の両方をロック解除中にも画面上部のポップアップバナー（heads-up 通知）として表示する。
- Android OS は既存チャンネルの重要度引き上げを後から反映しないため、チャンネル移行バージョンを `2` に更新し、起動時の `migrateLegacyNotificationChannels` で旧チャンネル（`reminder-silent` / `reminder-alerts`）の予約済み通知を新チャンネルへ再予約したうえで旧チャンネルを削除する。
- 文言変更のみが目的の通知は既存予約の一括再予約を行わず、新規作成・編集・チャンネル移行または権限復帰時の再予約から新しい文言を適用する。

## 実機確認と成功条件

- Development Build での確認手順は [QA_DEVELOPMENT_BUILD.md](QA_DEVELOPMENT_BUILD.md) の「9. ローカル通知」「12.1.1 終日リマインダー」に従う。
- ロック画面・バナー・通知一覧・長い予定名（40 文字）・大きい文字設定において、通知を開かずに「用件」「いつの予定か」「準備のためか、当日の知らせか」を短時間で説明できることを成功条件とする（開封率のみを成功指標にしない）。
